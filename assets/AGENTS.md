# assets/ — bundled runtime assets

Everything here is compiled into the app and loaded via `rootBundle`.
Declared in `pubspec.yaml`.

| Asset | What | Regenerated by |
|---|---|---|
| `final_model.json` | Daily RandomForest, **28 features**, RF 48×256, ~1.59 MB | `scripts/export_leadup_models.py` |
| `hour_model.json` | Hourly RandomForest, **22 features**, same shape | `scripts/export_leadup_models.py` |
| `flight_stats.json` | Score quantiles + isotonic calibration + base rate | `scripts/flight_stats_pipeline.py` |
| `.env` | **Gitignored.** API keys + DB password | you, by hand |
| `*.png`, `*.jpg`, `*.svg` | Imagery, app icon sources | `scripts/icon/` |
| `icon/` | Icon source art | |

## Never hand-edit the three JSON files

They are pipeline output. A hand-edit will be silently reverted by the next
regeneration, and in the meantime it can desynchronise the model from the
feature order in `lib/controller/nuptials.dart` — which produces plausible
wrong forecasts, not a crash.

The two model files must be regenerated **together with** `flight_stats.json`:
the stats table is fitted by scoring the live DB with the shipped daily
model, so a new model with an old stats table gives users miscalibrated
bands and odds.

## `.env` is required even to run tests

`flutter analyze` and `flutter test` both fail without it. Template is in the
root [AGENTS.md](../AGENTS.md). Keys used:

```
OPENWEATHERMAP_API_KEY=   # paid One Call by Call subscription
OPENWEATHERMAP_MAP_KEY=
MAPTILER_MAP_KEY=
ARANGO_PASSWORD=
```

Never commit it, never paste a real key into a comment, commit message or
log. `redactUrl()` in `lib/utils.dart` exists because these keys were
previously reaching release-build device logs through `print`.

## Size matters here

Assets are downloaded by every user on every install. The current ~3.2 MB of
JSON is a deliberate trade: it replaced ~1.09 MB of *generated Dart* plus
0.30 MB JSON with 0.80 MB JSON and a 3 KB walker (later grown by the richer
feature sets). Before growing a model, check what it does to the web bundle
in particular — these gzip to roughly a third.
